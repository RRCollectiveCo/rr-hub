          Ritual & bundle contents

          When an order has a ritual or bundle, the station asks for each item inside it. Items marked "check size" were set from the product description, so confirm the sizes.

          Box sizes

          The station picks the smallest box whose space fits the order. Each product has a space number in the table below (a 2 oz jar is 1). List what goes in each box, like the box itself and a thank-you card, and those supplies come off inventory every time that box is used.
